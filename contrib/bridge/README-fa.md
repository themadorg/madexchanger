# پل دلتاچت با یه دستور

وقتی اینترنت بین‌الملل قطع میشه، این اسکریپت روی یه دستگاه که هم به رله داخلی و هم به رله خارجی دسترسی داره یه پل Madexchanger میسازه تا پیام‌های دلتاچت دوباره بین دو طرف رد و بدل بشن

## یه دستور، تموم

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/themadorg/madexchanger/main/contrib/bridge/install-bridge.sh)
```

اسکریپت ازت آدرس رله داخلی و خارجی رو میپرسه و بقیه کارها رو خودش انجام میده

- ابزارها و کلید SSH رو چک میکنه و اگه کلید نداشتی برات میسازه
- به هر دو سرور وصل میشه و مطمئن میشه `madmail` اونجا هست
- madexchanger رو میسازه و کانفیگش رو با یه توکن ادمین تصادفی ذخیره میکنه
- سرویس پل و تونل‌های SSH رو روشن میکنه و حواسش هست تونل‌ها همیشه بالا بمونن
- پل رو با `endpoint-cache` به هر دو رله معرفی میکنه
- آخر کار سلامت پل و تونل‌ها رو چک میکنه و یه خلاصه نشونت میده

## بدون سوال

```bash
./install-bridge.sh --yes \
  --ir-host root@ir.example.ir \
  --foreign-host root@203.0.113.50
```

گزینه‌های پرکاربرد

| گزینه | کارش |
|---|---|
| `--ir-domain` و `--foreign-domain` | اگه دامنه ایمیل رله با آدرس SSH فرق داره |
| `--mode direct --bridge-addr IP` | وقتی رله‌ها مستقیم به دستگاه پل میرسن و تونل لازم نیست |
| `--install-method go` یا `docker` یا `--binary FILE` | روش نصب madexchanger |
| `--port` | پورت پل، پیش‌فرض 19080 |
| `--simulate-outage` | برای تست، مسیر مستقیم دو رله رو با iptables میبنده |
| `--dry-run` | همه دستورها رو فقط نشون میده و به چیزی دست نمیزنه |

## کارهای بعدی

```bash
./install-bridge.sh --status     # وضعیت پل، تونل‌ها و رله‌ها
./install-bridge.sh --restore    # برگشت به حالت عادی بعد از وصل شدن اینترنت
./install-bridge.sh --restore --purge   # پاک کردن کامل پل از روی دستگاه
```

## چند تا نکته

- دستگاه پل باید روشن بمونه، هر وقت خاموش بشه پیام‌ها تو صف رله‌ها میمونن تا پل برگرده
- کاربر SSH روی سرورها باید root باشه یا sudo بدون پسورد داشته باشه
- توکن ادمین فقط تو `~/madexchanger/config.yml` ذخیره میشه و هیچ‌جا چاپ نمیشه
- لاگ کامل نصب تو `~/.config/madexchanger-bridge/install.log` هست
- پل فقط فرستنده، گیرنده و پاکت رمزنگاری‌شده پیام رو میبینه و متن پیام‌ها رو نمیتونه بخونه
